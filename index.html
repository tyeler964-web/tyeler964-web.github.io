Setup notes

1. Host the website

This site is hosted from the main branch using GitHub Pages.

2. Run the PaperLive server plugin

Configure the plugin's web API endpoint and API key on your Minecraft server.

3. Connect

Enter the API URL above. Your browser then requests data from your server. The API must permit browser requests (CORS) for the GitHub Pages origin.
