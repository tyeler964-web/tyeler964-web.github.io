# Firefly Studios / PaperLive

Firefly Studios — PaperLive, plugins, addons, and Minecraft Bedrock & Java tools.

## Deploy to Render

This repository is configured as a Render Static Site using `render.yaml`.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/tyeler964-web/tyeler964-web.github.io)

Click the button above, sign in to Render if needed, review the Blueprint, and approve the deployment. Render will use the `render.yaml` in this repository and deploy the `main` branch.

After the service is created, pushes to `main` are configured to trigger automatic redeploys.

## Local files

The site is a static HTML/CSS/JavaScript app. No Node.js build step or database is required for the current frontend.

## Important

Render deployment itself requires authorization to the user's Render account. GitHub repository access does not automatically grant this assistant access to the Render account, so the final Render approval must be completed in the Render dashboard.
